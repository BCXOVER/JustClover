# Локальный инвентарь / показ выбранных скинов в главном меню

Статус этой сборки: не реализовано. Скинченджер и его значения сохранены,
исправлено меню и добавлены цвета редкости. Фиктивного переключателя
«инвентарь» в меню нет. Общая синхронизация с другими клиентами отменена.

Переданный архив содержит обвязку, SDK представления UI и защищённый ресурс
ядра. В SDK нет CEconItem/PlayerInventory/SOCache API. `client.dll` и
`panoramauiclient.dll` из целевого CS:GO Legacy 8802 в рабочем наборе отсутствуют.
Поэтому в нём нельзя подтвердить ABI/привязки для добавления настоящих
локальных предметов, их экипировки и обновления Panorama.

Для следующего этапа нужен архив с **client.dll и panoramauiclient.dll**
из той же установленной CS:GO Legacy, которая показала build 8802.
Это игровые модули, не skeet.dll и не DLL от CS2.

План интеграции после проверки целевых модулей:

1. Прочитать выбранные предметы, раскраску, seed/wear и StatTrak из настоящих
   профилей исходного скинченджера, включая разные оружия и стороны.
2. Создавать временные клиентские CEconItem с отдельными ID в собственном
   разделе локального кэша. Не перезаписывать подлинные предметы пользователя.
3. Обновлять локальную экипировку и уведомления Panorama для инвентаря
   и отображения предмета в главном меню.
4. При выключении удалять только созданные нами записи и восстанавливать
   сохранённую локальную экипировку.
5. Проверить смену карты, переподключение, вход в главное меню, смену
   аккаунта и выгрузку. Проверки на подменённых объектах не заменяют запуск
   настоящего клиента.

Это клиентское отображение, оно не создаёт принадлежащие аккаунту предметы
в Steam и не меняет их серверное владение.
