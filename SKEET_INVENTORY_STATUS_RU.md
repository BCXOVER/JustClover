# Локальный инвентарь — результаты разбора

В этой DLL локальный инвентарь и отображение выбранных скинов в главном меню
пока не добавлены. Полученный bin.zip исследован без загрузки/запуска DLL.

- client.dll: PE от 2023-10-11, SHA256
  183d42fac8a4ecc24dc02edf5f09122f37fe9e7533ca093a867718b25cfdeb03.
- client_panorama.dll: PE от 2020-06-02. Это другой, старый клиент,
  а не panoramauiclient.dll. Его адреса с первым модулем не смешиваются.
- В client.dll подтверждены фабрика CEconItem (RVA 0x6ea210), установка
  атрибутов (0x6da0e0), ItemSystem (0x712740), поиск type cache (0x82ea10).
- Подтверждён CCSInventoryManager: таблица из 36 виртуальных методов,
  RVA 0xcace9c. Получение локального инвентаря — слот 23; указатель хранится
  по смещению 0x38300. Размер выделения EconItem — 56 байт.
- ВАЖНО: слот 29 updateInventoryEquippedState вызывает отправку сообщения
  в Game Coordinator (call по RVA 0x6e6812, цель 0x82afa0).
  Его нельзя назвать только локальным обновлением экипировки.

Дальнейшая интеграция требует перехвата отправки только для собственных
временных предметов, сохранения и восстановления настоящей локальной
экипировки и точного чтения всех настоящих профилей skinchanger. При смене
карты/аккаунта/отключении нужно удалять только собственные временные записи.
Ни этот механизм, ни соответствующая фиктивная галка сейчас не установлены.

Аудит указанных фактов: tools/audit_client_module.py и
reports/client_module_audit.json. Сигнатуры поиска: data/inventory_pattern_audit.json.
Публичная справка по API: Osiris, commit
119f34386bb44e7cea0e7fd469201ae33354b8d5 (Source/CSGO/ItemSchema.h,
Source/InventoryChanger/GameIntegration/Inventory.cpp). Справка не заменяет
проверку в настоящем целевом клиенте.

Обмен скинами между пользователями отменён по предыдущей просьбе.
