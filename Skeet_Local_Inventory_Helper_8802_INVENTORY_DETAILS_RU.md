# Текущее подключение локального инвентаря

Реализованы: создание локального CEconItem, добавление в type cache,
уведомление CSPlayerInventory::SOCreated, удаление только собственных
предметов через SODestroyed/removeObject/деструктор и изменение UTF-8
неймтега через setCustomName/SOUpdated.

Дополнительно реализовано изменение четырёх RGBA-цветов CPaintKit
(цвета трактуются как непрозрачный RGB) с сохранением оригинала и защитой
от перезаписи последующих изменений другим модулем. Палитра общая для
одного paint kit. Изолированные экземпляры материалов не клонируются.

Проверенные RVA клиента 2023 года:

- 0x6ea210 — фабрика (выделение 56 байт), 0x6d8b20 — конструктор;
- 0x6da0e0 — динамический атрибут, 0x6d9160 — неймтег;
- 0x712740 — ItemSystem, schema getter возвращает this+4;
- 0x82ea10 — поиск/создание type cache класса 1;
- 0xcace9c — таблица InventoryManager, getter local inventory — слот 23;
- 0xcace34 — таблица CCSPlayerInventory, события 0/1/2 принимают SOID
  размером 16 байт по значению, object и event=4;
- 0x70adb0 — поиск paint kit в схеме (map по смещению 0x288);
- 0x6fd122/0x6fd138/0x6fd191 и 0x6fd2e3 — чтение/запись палитры
  по смещению 0x80, шаг Color=4, четыре элемента;
- 0x6cc7b0 — получение ItemView, 0x71b050 — очистка RGBA-изображения.

Ограничения: полностью работающая экипировка/восстановление реальной
экипировки, перехват стандартных операций Panorama, сохранение между
запусками и автоматическая замена старого механизма не реализованы.
Метод manager[29], отправляющий GC-сообщение, не используется.
