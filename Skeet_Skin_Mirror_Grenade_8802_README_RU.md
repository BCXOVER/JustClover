# Skeet: граната Helper и перенос выбранных скинов

CS:GO Legacy 8802, Windows x86. Готовая DLL: **bin/skeet.dll**.
Экспериментальная сборка: полный игровой запуск не проверялся.

## Выбранные скины из основного Skinchanger

В Skinchanger → Settings → Local inventory включён по умолчанию
**Sync Skinchanger selections**. Откройте нужный пресет оружия в обычном
Skinchanger, выберите скин и подождите примерно полсекунды. Для каждого
открытого пресета создаётся собственный локальный предмет: отделка,
модель ножа/перчаток, seed, износ и неймтег. Если тип оружия не определяется
однозначно, предмет не создаётся; включите Filter by weapon или выберите
модель явно. Счётчик StatTrak этим переносом пока не копируется.

При изменении пресета локальный предмет заменяется, а не добавляется
каждый кадр. Изменения объединяются с задержкой 350 мс; чтение пресета
ограничено 10 разами в секунду. Обход инвентарного кэша на простое
не выполняется каждый кадр.

Предмет локально экипируется для поддерживаемых сторон через клиентские
loadout-слоты и событие Panorama. Это подключение для локального loadout
и главного меню; **отображение модели в главном меню в игре не проверено**.
Неоткрытые сохранённые пресеты ядра автоматически не перечисляются:
откройте каждый нужный пресет хотя бы один раз за сессию.

При выключении синхронизации удаляются только перенесённые предметы,
восстанавливается прежний локальный loadout. Более поздний ручной выбор
пользователя сохраняется. Если удалить перенесённый предмет вручную,
он не создаётся заново до следующего изменения этого пресета.
Предметы, добавленные отдельной кнопкой вручную, не удаляются при
отключении синхронизации.

## Как открыть инвентарь

Skinchanger → Settings → **Local inventory**.
Кнопка открывает два собственных раздела внутри той же вкладки.
**Back to skinchanger** возвращает прежнее меню.

Слева выберите оружие/нож/перчатки, скин, seed и wear. Значение wear:
0 — минимальный износ, 10000 — максимальный. Нажмите
**Add to local CS:GO inventory**. Предмет создаётся в локальном кэше
клиента и публикуется через родное уведомление инвентаря, а не только
в собственном списке меню.

В списке **Local items** находятся только предметы, созданные этим модулем.
Кнопка **Delete selected local item** удаляет выбранный локальный предмет.
Чужие/настоящие предметы через этот список изменить или удалить нельзя.
Идентификаторы и позиции новых предметов выбираются после максимальных
существующих значений, с проверкой переполнения.

Справа можно ввести неймтег: **Apply name tag** применяет его,
**Remove name tag** очищает. Поддерживается UTF-8, включая русские буквы,
до 32 символов. Эти операции относятся к выбранному локальному предмету.

Предметы не добавляются на Steam-аккаунт и не сохраняются после закрытия
игры/очистки соответствующего кэша. Торговля, обмен и серверное владение
не добавлены. Стандартная GC-экипировка фиктивного предмета через меню
CS:GO не перехватывается. Для ручного предмета используйте
**Equip selected item locally**; синхронизация экипирует свои предметы сама.
Прежний механизм скинченджера сохранён; это дополнительный раздел,
а не полное удаление защищённой реализации ядра.

## Собственные RGB-цвета

Выберите добавленный предмет в Local items. Четыре Color picker меняют
четыре цвета палитры его paint kit. **Apply RGB palette** записывает палитру
и сбрасывает изображения собственных предметов этого типа.
Для просмотра результата закройте и заново откройте осмотр предмета.
**Restore original palette** восстанавливает цвета до первого изменения.

Палитра **общая для одного paint kit во всём локальном клиенте**. У двух
экземпляров одинакового скина нет изолированных независимых палитр.
Результат зависит от материала: некоторые отделки используют часть цветов
или собственную текстуру; нельзя обещать перекрасить любой рисунок четырьмя
цветами. Обновление уже созданных 3D-материалов в руках не подтверждено.

Удаление последнего собственного предмета этого paint kit пытается вернуть
исходную палитру. Если другой модуль изменил её после нас, автоматическое
восстановление не перезаписывает его изменения. При смене сессии список
собственных ссылок очищается, а отслеживаемые палитры восстанавливаются
только при совпадении живого объекта и последнего записанного значения.

## Helper в Visuals

Категория с иконкой появляется при наличии живого **чекбокса Helper**
в исходном дереве Visuals. Это проверка наличия контрола после загрузки,
а не проверка имени Lua-файла или состояния галочки.

В категорию переносятся Helper, его соседние color/hotkey/multiselect
контролы, распознанные параметры Aim at location, Show locations behind walls,
Hide duplicate locations и параметры с названием Grenade Helper.
Остальные настройки, включая обычный ESP гранат, сохраняют прежнее место.
Если скрипт создаёт дополнительные параметры с другими названиями, они
сохраняются в исходной категории и не теряют свои обработчики.

После выгрузки чекбокса категория скрывается. Если она была выбрана,
меню возвращается в World. Повторная загрузка возвращает категорию без
сброса остальных настроек Visuals.

Шестерёнка заменена на собственный силуэт гранаты с кольцом и рычагом.
Исходник: data/icons/helper.svg; результат: Helper_icon_preview.png.
Иконка растеризуется при сборке, внешний SVG-код в игре не исполняется.

## Совместимость

Инвентарь подключается только к переданному client.dll от 2023-10-11:
SHA256 183d42fac8a4ecc24dc02edf5f09122f37fe9e7533ca093a867718b25cfdeb03,
PE timestamp 0x65272025, SizeOfImage 0x5509000.
Проверяются версия и конкретные инструкции/таблицы; в неподходящем
клиенте операция возвращает ошибку вместо записи по угаданным адресам.
client_panorama.dll 2020 года с ним не смешивается.

Код client.dll не изменяется. Метод InventoryManager №29,
который отправляет GC-экипировку, новый модуль не вызывает.
Не добавлены никакие сетевые сервисы синхронизации.

Сохранены исправления resize/DPI, редкости скинов и ранее установленные
игровые патчи. ESP-превью полностью удалено: без манекена, игровой модели,
панели Manage elements и собственного перехвата мыши. Настройки Visuals
используют всю доступную ширину меню. Экспериментальная 3D-модель
Мясника / Phoenix из отменённого черновика в эту сборку не включена.
Glacier, Amethyst, Crimson и Champagne остаются удалёнными.

## Проверки

- Проверки синхронизации: задержка, отсутствие дубликатов, замена пресета,
  отключение/возврат loadout, ручное удаление и смена аккаунта.
- Исполнение клиентских методов экипированного состояния, определения
  loadout-слота, локального setter и события Panorama в x86-эмуляторе;
  сохранение последующего ручного выбора, очистка флагов перед удалением,
  запрет вызова отправки GC в проверяемом пути.
- 117 случаев проверки данных, владения, отката ошибок и смены аккаунта.
- Изолированное исполнение фабрики/конструктора EconItem, поиска type cache,
  getter paint kit и оболочек трёх событий инвентаря из переданного клиента.
- Проверка ABI трёх атрибутов (paint, seed, wear), UTF-8 неймтега,
  чтения/записи/возврата палитры, отказа при другом клиенте и сохранения
  внешних изменений палитры.
- Свежие родные контролы нового раздела: 4 color picker, вызовы кнопок,
  пять циклов размера/DPI, отсутствие новых выделений на простое и повторном
  открытии, сохранение ссылок и callbacks при перестройке старого skin UI.
- Загрузка/выгрузка Helper с выбором категории и удалением её источника.
- Прежние проверки родных контролов, Lua lifecycle, resize/DPI, ресурсов
  DLL/EXE и совместной установки игровых модулей.

Границы тестов: полная игра и защищённый старт не выполнялись. Выделение
памяти и часть игровых API/обработчиков заменены контролируемыми fixtures.
Эти проверки не доказывают отображение инвентаря и RGB на реальном клиенте.
Отчёты находятся в reports/. Исходные игровые DLL в архив не включены.

После замены bin/skeet.dll полностью перезапустите игру.
Исходные бинарные ресурсы защищённого ядра сохранены побайтно;
полный высокоуровневый исходник ядра не восстановлен.

## Сборка и воспроизведение

```sh
python -m pip install -r requirements-build.txt
python build_windows.py
python tests/validate_visuals.py
python tests/validate_skin_mirror.py
python tests/validate_release.py
python package_release.py
```

Native inventory fixture требует переданный client.dll и mapped image
в /workspace/game-8802-modules; его старт не запускается.
Дополнительные проверки: tests/local_inventory_plan.cpp,
tests/local_inventory_client_probe.cpp, tests/validate_inventory_client.py.
Геометрия и SVG: tools/build_helper_icon.py (Pillow + svgpathtools).
Источник сведений об ABI: Osiris, commit
119f34386bb44e7cea0e7fd469201ae33354b8d5; каждое использованное смещение
проверялось отдельно на переданном client.dll.
