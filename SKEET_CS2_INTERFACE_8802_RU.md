# CS2 interface — CS:GO Legacy 8802

База: bcc35a5230b9ad6420cee02086f17f6e5a06b110. Это адаптация интерфейса для Source 1. Полное визуальное совпадение 1:1 и работу внутри игры здесь не проверяли: игровой процесс и GPU не запускались.

## Исправления

- Отсечение ESP preview: ResetBounds(true) включает D3DRS_SCISSORTESTENABLE, а не выключает его. Временный оверлей теперь выключает scissor и восстанавливает его прежний прямоугольник и состояние. Проверен настоящий нативный потребитель команды, а не только наличие команд рисования.
- Шестерёнки: клик обрабатывается перед нативным CMenu. Нажатие не передаётся чекбоксу всей строки. Окно появляется в том же кадре; до отпускания мыши исключено сквозное нажатие. Область открытого окна имеет приоритет над шестерёнками под ним.
- Сохранены семь групп: Multi-point, Quick stop, Quick peek assist, Double tap, Accuracy boost, Minimum damage override, Minimum hit chance override. Основные переключатели остаются в главном списке; бинд и дополнительные значения открываются в маленькой панели.
- ESP preview остаётся справа внутри Visuals → Enemy. Используется штатная CT SAS и прежний рендер моделей. Если модуль/ассеты/текстура недоступны, теперь должна быть видна диагностическая надпись. Проверка модельного рендера использует заменённые GPU/asset boundaries, поэтому живой игровой кадр остаётся обязательной практической проверкой.

## World

Категория с глобусом: Entity ESP сверху слева, Grenade ESP снизу слева, World effects справа на всю высоту. Существующие функции Legacy сохранены.

В World effects добавлены:

- Override sky: Default, Night, Night 2, Daylight, Vertigo, Vietnam, Custom.
- Custom skybox name: базовое имя существующего Source 1 skybox, например sky_csgo_night02. Нужны шесть установленных skybox-материалов; архив не содержит новых текстур. Имена .vmap/sky-объекты CS2 не поддерживаются.
- Sky color: RGB-модуляция материалов неба. Сохраняются прежние цвета и удерживаются/освобождаются ссылки материалов.
- Override lighting: RGB-компоненты ambient light Source 1.
- Override fog: цвет, начало, конец и плотность, включая skybox fog. Конец всегда дальше начала. Прежние cvar возвращаются при выключении/выгрузке; после смены карты снимок берётся заново.

Нативные Remove fog / Remove skybox могут конфликтовать с соответствующими override: для оценки нового эффекта отключите удаление того же эффекта. Source 2-only keychains, пятый слот наклейки и прочие неподдерживаемые функции не добавлены.

## Наклейки

В Skins → Model customization появляется редактор для оружия, выбранного в штатном Weapon skin. Он не определяет оружие по происхождению отделки, поэтому Filter by weapon не меняет цель редактирования.

- Четыре слота Legacy. Выбор Slot 1…4, поиск по имени, выбор Sticker, износ, масштаб и поворот.
- None снимает наклейку только выбранного слота. Ножи, перчатки и агенты не получают редактор оружейных наклеек.
- Каталог: 6711 наклеек из схемы Legacy e63fc7fdb8dfb4f1873f0db214c0cc16613d5beb; патчи и граффити исключены. После поиска показывается максимум 62 строки, включая None и текущую наклейку.
- Применение автоматическое. Изменение наклейки заменяет синхронизированный локальный предмет и обновляет его ID; отсутствие изменений не создаёт новые предметы.
- Атрибуты 113…128 заполняются в настоящем локальном CEconItem. ID записывается целым числом, wear/scale/rotation — float. Связка собственного оружия проверяет GetSOCData; чужое оружие не переписывается. Сохранённые ID отслеживаются по полному handle, включая serial, а не по позиции в списке оружия.
- Настройки хранятся в локальной database GameSense. Если ядро предоставляет ui.new_string, полный набор слотов также хранится в скрытом поле конфига Clover sticker profiles 8802. Сохраняются ID и weapon, а не индексы отфильтрованного списка. Без этой возможности работает локальное сохранение database. Повреждённая запись конфига не применяется частично.

Это клиентский локальный инвентарь, как в предыдущей версии. Предметы не выдаются аккаунту Steam и другим игрокам не передаются. Редактор сейчас использует выбор слота и поиск, а не пять кнопок миниатюр из примера CS2.

## Misc: watermark и logs

MISC → Miscellaneous: CS2 watermark и CS2 logs. За основу взяты оба приложенных Lua; сохранены их источники в source/lua/*.original.lua. Встроены используемые функции color/easing/vector, скачивание зависимостей не требуется.

Watermark: имя, FPS, variance, ping, адрес сервера, скорость, K/D, часы, CPU usage, CPU frequency, RAM, Game memory. Отдельные показатели выбираются в Watermark elements. CPU usage берётся из GetSystemTimes, RAM — из GlobalMemoryStatusEx, Game memory — WorkingSet процесса. Частота — средняя текущая MHz, которую сообщает Windows через CallNtPowerInformation; если данных нет, значение не выдумывается. Опрос системы не чаще раза в секунду.

Logs: попадания, промахи и покупки, отдельные цвета; ограниченная очередь, появление и затухание как в приложенном скрипте.

Модуль встроен в DLL и автоматически записывается/загружается как clover_cs2_ui_8802.lua в рабочей папке игры. Вручную загружать исходные notify.lua и watermark.lua не нужно. Разрешение загрузчика для внутреннего FFI применяется только во время загрузки и возвращается к прежнему значению. Собственные настройки модуля сохраняются при выгрузке Lua. Пропажу его heartbeat DLL обнаруживает по времени и числу кадров и восстанавливает модуль; первое возвращение из свёрнутого окна не вызывает перезагрузку.

## Проверки и сборка

- build/build-run.log: перекомпиляция Windows x86 DLL и EXE. Защищённые исходные ресурсы не менялись.
- reports/menu_interaction_validation.json: настоящие клики/удержание, видимость pop-up, закрытие и приоритет открытой панели.
- reports/override_preview_validation.json: отрисовка за пределами нативного scissor Category, ввод и сохранение цепочки Lua renderer.
- reports/addon_bootstrap_validation.json: точное содержимое встроенного Lua, ABI загрузчика, ограниченное разрешение, восстановление после выгрузки.
- reports/lua_ui_validation.json: LuaJIT с подставными GameSense/FFI API; редактор, конфиги, сохранение при reload, World restore, watermark и logs.
- reports/inventory_validation.json: оригинальные функции клиента в Unicorn, четыре атрибута каждого слота, GetSOCData, чужое оружие и перестановка слотов.
- reports/menu_baseline_validation.json: исходники стрельбы, hitscan, resolver, DT, предикта и инжектора совпадают с базовой версией.

Повторная сборка: pip install -r requirements-build.txt, затем python build_windows.py. Встроенный Lua обновляется автоматически. Для Lua-проверок дополнительно pip install -r requirements-tests.txt. Остальные закрытые проверки: tests/validate_visuals.py, validate_inventory_client.py, validate_skin_mirror.py, validate_release.py. Для module audit нужны предоставленные файлы клиента 8802; они не включены повторно.
