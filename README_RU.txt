Andromeda: скачивание полного файла и получение трассы

1. Полностью распакуйте этот ZIP. Замените старый andromeda.lua файлом
   andromeda.lua из архива. Это тот же полный файл реконструкции, который
   опубликован как Andromeda_reconstructed.lua: 6 145 254 байта, 348 363 строки.
   Используйте извлечённый файл; копирование большого текста может его обрезать.

2. Ошибка ") expected near <eof>" на строке 62227 воспроизводится, если
   обрезать полный исходник на этой строке. Полный файл компилируется
   в LuaJIT 2.0 и 2.1. Если ошибка остаётся после замены, приложите именно
   локальный andromeda.lua, который выдаёт ошибку: это позволит сравнить байты.

3. Для получения трассы запустите отдельно Andromeda_capture.lua в GameSense.
   Выгрузите другую копию Andromeda перед запуском диагностики.
   Восстановленный andromeda.lua сам трассу не создаёт.

4. Диагностика создаёт andromeda_vm_trace.txt сразу после начала выполнения.
   Путь относительно каталога игры: csgo/andromeda_vm_trace.txt.
   Пример для стандартной установки:
   Steam/steamapps/common/Counter-Strike Global Offensive/csgo/andromeda_vm_trace.txt
   Сообщение [Andromeda trace] SAVED AND VERIFIED означает, что файл записан
   и прочитан обратно. WRITE COMPLETED означает запись без проверки чтением.
   NOT SAVED или NOT VERIFIED означает проблему записи; пришлите сообщение
   из консоли. Не ищите трассу, если сам capture-файл не прошёл загрузку.

5. После запуска подождите несколько секунд и выгрузите диагностику,
   чтобы сохранить последнюю трассу. Пришлите TXT и ошибку из консоли.
   Диагностика сохраняет номера функций, адреса инструкций и числовые операнды.

Это частичная деобфускация: все 564 функции присутствуют, пять сохраняют VM.
Работа приложения в GameSense в этой среде не проверена.
Подробности: RECOVERY_STATUS_RU.txt. Контрольные суммы: SHA256SUMS.txt.
