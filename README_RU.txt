Andromeda — самостоятельный запуск восстановленного приложения

Основной файл: andromeda.lua. Выгрузите прежние копии, полностью распакуйте
архив, замените andromeda.lua и запустите только этот файл в GameSense.

Исправление ошибки max: number expected, got table
В предыдущей сборке ключ env_functions["math.clamp"] ошибочно считался обычным
числовым clamp. Здесь защита использовала этот ключ как обработчик отказа
и передавала таблицу ban_num/ban_info. Числовая подмена полностью удалена.

Новый f1 напрямую создаёт основную часть Andromeda (f96), передаёт ей ffi,
модуль SHA256/HMAC и таблицу из 103 исходных ссылок на API в правильном порядке.
Прежний блок обмена с загрузчиком Odyssey при таком запуске не выполняется.
Все 103 позиции и ссылки сравнены с настоящими таблицами старого инициализатора.
Сохранён существующий _SCRIPT_NAME. При его отсутствии локально используется
имя andromeda, соответствующее имени файла в архиве. Исходное окружение
и чужая таблица env_functions не изменяются.

Три аварийных обработчика f108/f115/f416 отключены; связанные регистрации
и запрос player_request_hint в начальной части f96 удалены с сохранением
состояния аргументов. Четыре прежние ловушки f47/f109/f116/f418 завершаются
явной ошибкой при прямом вызове. Код настройки старого загрузчика сохранён
среди определений для разбора, но новый вход его не вызывает.

В файле сохранены 564 фабрики функций. Общий VM-интерпретатор удалён.
Низкоуровневые регистры и переходы в восстановленном коде ещё присутствуют.
Пять XOR-помощников f3/f48/f112/f117/f419 используют bit.bxor для uint32;
для остальных входов сохранены прежние арифметические тела.
Ограничения запуска и выполнение порциями сохранены.

Проверки текущего файла
LuaJIT 2.0 и 2.1: компиляция и создание всех 564 фабрик.
24 проверки самостоятельного входа: воспроизведение прежней ошибки max;
сравнение всех 103 имён и ссылок на функции; настоящий f96 доходит до запроса
модуля gamesense/pui без обращения к env_functions; проверка сохранения имени
скрипта, трёх отключённых обработчиков и четырёх аварийных ловушек.
Игра и нативные игровые API в этих проверках заменены ограниченными макетами.
Содержимое gamesense/pui, игровые функции и появление меню здесь не проверены.

Пять XOR-функций сравнены с оригинальной обфусцированной VM на 331220 парах.
Синтетическая нагрузка из 125000 XOR завершается за 62 порции в обоих LuaJIT;
прямой вызов аварийной ловушки прекращается в первой порции.
Подробности и ограничения находятся в reports/. SHA256SUMS.txt содержит суммы.
