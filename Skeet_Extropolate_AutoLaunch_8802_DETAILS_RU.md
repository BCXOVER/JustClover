# Extropolate: интеграция в Ragebot, Legacy 8802

Один нативный checkbox `Extropolate` добавляется первым в правую секцию
`Other` вкладки Ragebot. Работает через собственный атомарный флаг для
scan workers. Загрузка/выгрузка Lua и перестройка дерева UI не оставляют
старую ссылку: объект проверяется в живой коллекции и при необходимости
создаётся заново с прежним состоянием. В новой сессии включён по умолчанию.

Патч установлен до генерации точек в scan worker 0x4335cd37, перехват
0x4335cd45..0x4335cd4e. Job содержит полную запись по смещению +0xf0:
origin +0x120, tick +0x13c, flags +0x14c, кости +0x320. Копия применяется
только если она побайтно совпадает с новейшей записью истории и текущей
позицией истории. Старые выбранные записи и альтернативные позы сохраняются.

Ищется самый длинный допустимый прогноз до 8 тиков. Все 19 матриц основной
позы и, при наличии, трёх дополнительных наборов сдвигаются вместе с origin;
tick обновляется в той же копии job. Последующие поиск точки и проверка
попадания видят одну запись. История и её оригинальные матрицы не меняются.

Границы: native_upper, текущее время, родная временная коррекция, не более
64 единиц смещения; 3 наблюдения для короткого, 4 для длинного прогноза;
проверка остановок/разрывов, скорости и направления, вертикального
ускорения. Длинный прогноз требует более строгого согласия сегментов и
стабильного yaw. Каждый шаг проверяет swept hull; при препятствии горизонт
сокращается. Cvars, окно backtrack и ограничения сервера не расширяются.
Выключение прекращает новые прогнозы; согласованная интерполяция и остальные
сохранённые модули работают по-прежнему. Существующий расчёт летальной точки
корпуса сохраняется, но прогноз сам по себе не гарантирует летальный выстрел.

Отдельные буферы на worker выделяются один раз через TLS. Не создаётся
большой Scratch-массив на стеке. При перехвате сохраняются flags, все общие
регистры и состояние x87/SSE; точные исходные инструкции проверяются до записи.

Проверки: tests/validate_rage_prediction.py выполняет production bridge и
подменённый только в engine API новый пролог Rage worker в x86 эмуляторе:
305 проверок матриц/границ/отказов и 6 размещений/состояний ABI; UI fixture
проверяет положение, переключение, отсутствие дублей и пересоздание объекта.
Это проверки интеграции на закрытых fixtures, не измерение точности в игре.

Инжектор теперь читает Steam registry/libraryfolders.vdf/appmanifest_730.acf
и проверяет PE32 csgo.exe. Запускает игру suspended, резервирует фиксированный
адрес ядра, возобновляет поток и ожидает нужные модули перед LoadLibraryW.
На выходе до возобновления RAII пытается возобновить созданный поток, чтобы
ошибка загрузчика не оставила новую игру замороженной. Ошибка/таймаут не
завершает чужой процесс. DLL берётся строго рядом с injector.exe.

DT accuracy / check spread DT / 2bullet из предыдущего релиза удалены.
Сохранена поэтапная индексация агентов и остальные исправления Skinchanger.
Защищённые бинарные ресурсы ядра не перепаковывались и не менялись.
Для удаления уже установленных старых перехватов нужен перезапуск игры.
