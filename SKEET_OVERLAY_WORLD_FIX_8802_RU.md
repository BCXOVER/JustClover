# Исправления по последним игровым скриншотам

База: b14d60b73413773add822a5bc8974763f3383b33, Skeet_CS2_Interface_8802. Скриншоты пользователя подтверждали реальные регрессии предыдущей сборки; старые закрытые проверки их не выявляли.

## Окна шестерёнок

Маленькие панели исключены из обычного прохода дочерних панелей Ragebot. Выбранное окно отправляется отдельным проходом после основного меню и переходной заливки, с отключённым scissor и верхним Z. Прежние scissor, границы, alpha и depth возвращаются после рисования. Нативные элементы ввода, привязки клавиш и их модели сохранены. Клик по шестерёнке не включает чекбокс под ней.

Проверка воспроизводит случай, когда окно находится в списке раньше Aimbot/Other: в обычном проходе оно ничего не рисует, в финальном отправляется последним. Это проверка порядка и состояния рендера с заменённым GPU, а не свидетельство реального игрового кадра.

## Загрузка пропавших функций

Причина видимой ошибки module 'clover_cs2_ui_8802.lua' not found: Lua require рассматривает точки в имени как разделители пути. Файл по-прежнему называется clover_cs2_ui_8802.lua; имя для нативного загрузчика теперь clover_cs2_ui_8802. Новый тест использует настоящий LuaJIT require и воспроизводит старый сбой перед проверкой исправления. Игровые API в нём подставные.

Каждый из четырёх модулей сообщает об успешной инициализации. Если World или Stickers не инициализируются, соответствующая вкладка показывает сообщение проверить консоль. Для редактора наклеек предусмотрены штатные названия контейнеров Model options / Knife options / Weapon skin; проверен отказ первого контейнера и успешный выбор второго.

Наклейки: четыре слота, поиск по каталогу, ID в конфиге, отдельные настройки каждого оружия, удаление None. Используется ранее добавленный мост атрибутов 113–128 в принадлежащие модулю локальные предметы. Он не переписывался в этой версии. Нативные результаты его прошлых проверок помечены как унаследованные.

## ESP

Десять названий элементов и их цветовые спутники скрыты только в левой панели Enemy ESP. Настройки доступны в Manage elements по шестерёнке превью; обычные настройки моделей остаются в Enemy models. Исходные контролы, адреса моделей и обработчики config/value не удалены. Выбор цвета меняет исходный RGBA и вызывает прежние callbacks, поэтому превью и игра используют одни данные. Проверены запрет изменения недоступного цвета и отсутствие изменения исходной видимости/значений при переносе.

Убраны технические подписи Elements / Drag flags around player / Layout also applies in game. Само перетаскивание флагов сохранено.

## World

Новые Night mode / интенсивность / World color / Prop color используют ColorModulate только для World и StaticProp материалов. Небо, оружие, интерфейс и модели игроков не затрагиваются. Сохранены исходные цвета; ссылки материалов удерживаются до восстановления. За кадр обрабатывается не более 64 записей, повторный поиск — не чаще раза в секунду. При выключении возвращаются собственные изменения; более поздний цвет другого модуля не затирается. После смены карты выполняются восстановление и повторный захват.

World effects начинается с новых настроек, поэтому они доступны без прокрутки через все старые эффекты. Override sky поддерживает существующие skybox и Custom: материалы materials/skybox/<имя>rt/lf/bk/ft/up/dn.vmt и нужные им VTF. Архив не содержит новых текстур. Source 2 sky-объекты не совместимы с Legacy. При ненайденном skybox видна диагностика, прежнее небо сохраняется.

Override fog: цвет, начало, конец и плотность; Override lighting: ambient RGB. Конфликтующие штатные Remove fog / Remove skybox / Brightness adjustment временно отключаются при соответствующем override и возвращаются после выключения. Подробные возможности наклеек, watermark/logs и неба описаны в CS2_INTERFACE_RU.md.

## Проверки и ограничения

- Пересобраны skeet.dll и injector.exe, Windows x86, без выполнения их entry point на хосте.
- 101 исходный файл сохранён побайтово; исходные защищённые ресурсы, стрельба, hitscan, resolver, DT, предикт, инвентарь и инжектор не изменены.
- reports/menu_interaction_validation.json: порядок popup, захват кликов, bind-редакторы, закрытие и восстановление рендера.
- reports/override_preview_validation.json: скрытие дубликатов ESP, исходные модели, RGBA callbacks, ввод превью и scissor.
- reports/lua_ui_validation.json: реальный require в LuaJIT с подставными игровыми API, fallback контейнера наклеек, config, World и телеметрия.
- reports/night_mode_validation.json: 200 материалов, лимит 64, фильтрация групп, интенсивность, смена палитры, ссылки и восстановление.
- reports/sticker_world_abi_audit.json: статическая проверка поставленных DLL 8802, slots перечисления материалов, загрузчика skybox и scissor.
- reports/menu_baseline_validation.json и inherited_report_provenance.json: точные изменения и происхождение результатов.

Живой клиент CS:GO и GPU в этой среде не запускались. Эти результаты не подтверждают визуальное совпадение 1:1 или отсутствие всех игровых ошибок. Архив содержит собранные файлы, исходники, diff к b14d60b и SHA256SUMS.txt.
