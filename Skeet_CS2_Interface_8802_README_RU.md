# Skeet CS2 interface — Legacy 8802

Готовые файлы: **bin/skeet.dll** и **bin/injector.exe**. Полные исходники, встроенный Lua и отчёты входят в архив. Основное описание: **CS2_INTERFACE_RU.md**.

1. Полностью закройте игру со старой DLL и распакуйте новый архив.
2. Запустите bin/injector.exe; он запускает установленную CS:GO Legacy x86 и загружает соседнюю skeet.dll. Нужны вход в Steam и работающий Steam overlay. При нестандартном пути: injector.exe --game "D:\SteamLibrary\steamapps\common\Counter-Strike Global Offensive\csgo.exe".
3. В Ragebot шестерёнки открывают отдельные панели. ESP preview закреплено справа в Visuals → Enemy.
4. World находится на категории с глобусом. Новые sky/fog/lighting появляются в World effects после автоматической загрузки встроенного модуля.
5. Наклейки: выберите оружие в Weapon skin, затем используйте Stickers в Model customization. Четыре слота; None удаляет наклейку. Перенос в локальный инвентарь автоматический.
6. Watermark/logs: MISC → Miscellaneous → CS2 watermark / CS2 logs. Отдельная загрузка приложенных Lua не требуется.

Исправлены обработка кликов по шестерёнкам и перепутанное состояние scissor, которое скрывало превью. Добавлены World-настройки, четыре слота наклеек с инвентарём и метрики CPU/RAM. Подробности проверки и ограничения — в CS2_INTERFACE_RU.md.

**Игровой запуск и точное визуальное совпадение 1:1 здесь не проверены.** Сборка и закрытые проверки пройдены; GPU и часть игровых API заменяются в тестах. Source 2-only функции не копировались. Редактор наклеек использует список/поиск, а не миниатюры CS2. Старые документы описывают историю проекта.

Перенос предметов остаётся локальным для клиента, без выдачи Steam-предметов или обмена с другими игроками. Стрельба, resolver, hitscan, DT и предикт в этой версии не менялись. Extropolate остаётся удалённым и выключенным.
