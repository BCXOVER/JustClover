# Andromeda: восстановленная версия

[Скачать ZIP](Andromeda_recovered_source.zip). В архиве только `andromeda.lua`.
Выгрузите старую Andromeda, распакуйте ZIP и замените Lua-файл.

Предыдущий файл на 2,535,676 байт был избыточным результатом восстановления.
Восстановитель многократно копировал общие ветви условий. Сам размер файла
не определяет наличие обфускации, но прежнее описание полной очистки было слишком категоричным.

Теперь файл занимает 1,188,485 байт. Изменена структура кода, а не только форматирование:
общие продолжения условий восстановлены с учётом return/break; удалены лишние
присваивания; 11,022 цепочек временных переменных свёрнуты в выражения;
701 записей таблиц объединены в конструкторы;
восстановлены 587 вызовов методов с двоеточием и обычные параметры функций.

Статус: **восстановленный код, не оригинальный проект автора**.
Имена `recovered_…`, `value_…`, `capture_…`, ячейки захваченных переменных и часть
служебных конструкций ещё присутствуют. Изначальные имена, комментарии и точное
оформление автора из предоставленного обфусцированного файла не восстанавливаются.
Удаление VM и переходов goto не означает автоматического восстановления всего
исходного кода на уровне авторских абстракций.

LuaJIT 2.0/2.1: полный запуск самого файла в локальной модели GameSense;
совпали все 1791 вызов интерфейса. Сравнение с прежним кодом также включает
338 результатов автономных функций, 4096 сценариев выбора hitchance и 154 импорта
конфигурации в каждом runtime. Отдельно проверены порядок вычислений,
многозначные возвраты, область видимости и захваченные переменные.
Нативные GameSense API и игровые callback-функции в настоящей игре здесь не запускались.
