# Восстановленный исходный код Andromeda

Здесь выделен весь Lua-код сборки, запуск и меню которой пользователь подтвердил
в GameSense. Функциональные изменения при выделении не вносились: результат
сборки совпадает с рабочим файлом побайтно.

Это восстановленный код, а не оригинальный репозиторий автора. Идентификаторы
`f1`–`f564`, регистры, переходы `goto` и часть прежних данных сохранены.
Первоначальные имена локальных переменных и комментарии автора утрачены.
Названия некоторых файлов описывают установленное назначение функций.

## Где редактировать

- `src/functions/f096_application.lua` — основная часть, меню и регистрация событий.
- `src/functions/f001_standalone_entry.lua` — самостоятельный запуск и привязки API.
- `src/functions/f255_screen_anchor.lua` — расположение элементов на экране.
- `src/functions/f179_signed_round.lua` — округление.
- `src/functions/` — все 564 определения, каждое в отдельном файле.
- `src/runtime.lua`, `src/program_data.lua`, `src/function_factory.lua` — общие
  помощники, данные прототипов и создание замыканий.
- `src/optimizations.lua`, `src/startup.lua` — оптимизации XOR и запуск порциями.
- [FUNCTIONS.md](FUNCTIONS.md) — полный указатель с именами файлов.
- `docs/application_api_bindings.json` — справочник привязок API.

Части `src/` собираются в один лексический блок с общими `local`-переменными.
В GameSense загружается итоговый файл `dist/andromeda.lua`.

## Сборка

Нужен Python 3.9 или новее, дополнительные пакеты не требуются.

```sh
python build.py
```

После правок снова выполните эту команду и замените Lua в игре результатом из `dist/`.
Для проверки исходного снимка до внесения правок:

```sh
python build.py --check
```

Базовый файл: 6109002 байт. SHA256:
`ab3f9e313ba4e66cfdca66f6733ab19748151851042892a73162a6d741bd6419`.

Меню и завершение запуска подтверждены пользователем; работа всех игровых функций
этим не подтверждена. Для дальнейшего превращения регистров и переходов в привычные
`if`/`for` и осмысленные локальные переменные потребуется отдельная работа.
