# Skeet — хитскан и предикт без переключателей

Для CS:GO Legacy 1.38.8.1, build 8802, Windows x86.
Готовая библиотека: **`bin/skeet.dll`**. Замените DLL предыдущей сборки.
В архив также включён прежний `bin/injector.exe`.

## Что изменено

- Полностью удалена наша добавка к BT: поля глубины, настройка 200 мс и
  ограничение нижней границы по возрасту записи. Нижнюю временную границу
  снова задаёт исходный код. Штатный backtrack самого ядра сохранён.
- Удалено создание всех десяти наших элементов меню: семь галок и три ползунка.
  Их названия также отсутствуют в готовой DLL. В блок `Other` ничего не вставляется.
- Патчи хитскана включены постоянно: проверка отказа применения записи,
  округление порога попадания вверх и режим 64 образцов разброса.
- Предикт включён постоянно: горизонт до **2 тиков**, согласованная
  интерполяция с промежутком до **8 тиков**, проверка препятствий и
  сокращение прогноза при нестабильном движении.
- Переключатели хитскана размещены в неизменяемых данных PE; настройки
  предикта заданы константами C++. Старые конфиги не управляют этими патчами.

Подготовленная поза повторно используется выбором точки и применением.
Экстраполяция ограничена реальными образцами, допустимым временем и
проверкой player hull. При отсутствии надёжных данных будущая поза отклоняется.
Число 2 означает верхний предел горизонта; фактический прогноз может быть короче.

## Меню Gamesense CS2

**В этой сборке оставлено исходное оформление Skeet CS:GO.**
Полная копия интерфейса Gamesense CS2 пока не реализована: подтверждённый
визуальный эталон найти не удалось. Нужна ссылка на видео или страницу,
где видны нужное оформление и вкладки. Произвольная тёмная тема в эту
сборку не добавлялась. Эта DLL предназначена для CS:GO Legacy.

## Проверки

В `reports/` находятся отчёты проверки сборки, ресурсов PE, отсутствия
наших пунктов меню, неизменяемых флагов, сохранения нижнего диапазона
после удаления BT-добавки и согласованности геометрии.
Проверены родной селектор, интерполяция, подготовка применения,
движение, повороты, препятствия, кэш, 32/64 образца и пороги попадания.

Проверки выполнялись в закрытых x86 fixtures с контролируемыми заглушками
TLS и функций движка. DLL не запускалась в игре. Меню в реальном клиенте,
FPS и процент попаданий при сетевой задержке не измерены.

## Исходники

Полная обвязка и открытый C++ код патчей находятся в `source/`.
Бинарный ресурс исходного защищённого ядра сохранён побайтно;
его полный высокоуровневый исходник не восстановлен.
Различия с предыдущей сборкой: `AlwaysOn.diff`.
Контрольные суммы файлов: `SHA256SUMS.txt`.

```sh
python -m pip install -r requirements-build.txt
python build_windows.py
python tools/audit_blend.py
python tests/validate_motion.py
python tests/validate_scan_patch.py
python tests/validate_precision.py
python tests/validate_release.py
python tests/validate_resolver.py
```

Для генераторов тестовых переходников требуется `g++`.
