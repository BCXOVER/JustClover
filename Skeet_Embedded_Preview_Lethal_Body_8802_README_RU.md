# Skeet: встроенный ESP preview и выбор смертельной точки корпуса

CS:GO Legacy 1.38.8.1, build 8802, Windows x86.
Готовый файл: **bin/skeet.dll**. Сборка не проверена в запущенной игре.

## Что изменено

- Удалены Glacier, Amethyst, Crimson, Champagne и все четыре списка color preset.
  Обычные штатные цвета, материалы, модели и сохранённые значения сохранены.
- ESP preview рисуется внутри Visuals, справа от двух колонок настроек.
  Место выделяется до отрисовки меню и не зависит от свободного места на экране.
- Отрисовка перенесена в настоящий обработчик дочерней панели категорий,
  где уже работают иконки. Ошибка подключения оконного ввода не скрывает
  изображение. Больше нет условий по HWND из поля меню, ScreenSize или
  неподтверждённому MenuAlpha; используются штатная глубина и прозрачность рендера.
- При переключении Enemy / Team / View меняется объект предпросмотра.
  Enemy / Team / Self / Weapon в самой панели позволяют выбрать его вручную.
  Модель и Manage elements видны одновременно. Удалять/открывать панель кнопкой не нужно.
- Переключатели элементов обращаются к реальным доступным настройкам ESP.
  Их значения не меняются от самого открытия панели. Оконный ввод лишь
  ставит события в очередь, а обработчики ядра вызываются в потоке меню.
- Растеризация иконок категорий кэшируется до изменения геометрии,
  масштаба, категории или наведения. Она не повторяется полностью каждый кадр.

Предпросмотр — процедурный объёмный манекен и условная винтовка.
Это **не настоящая игровая CT/T-модель** и не точное воспроизведение материалов.
Здоровье, подпись оружия и флаги в примере иллюстративные.
Новые игровые модели и шейдеры не добавлены.
ESP_Preview_Embedded.png создан из команд тестового рендера; это не кадр игры.

После замены DLL полностью закройте и заново запустите игру:
переименование файла не заменяет уже загруженный модуль.

## Приоритет смертельного корпуса

Добавлен узкий патч в родной Rage scan worker (0x4335cd37), после получения
списка уже рассчитанных и допущенных точек. Место установки — 0x43360774.

Если выбранная точка относится к ноге, патч ищет в этом же списке грудь
или живот с рассчитанным уроном не ниже здоровья цели, используемого родным
заданием. Он сохраняет штатную маску приоритета: точка с более низким
родным приоритетом не подменяет исходную. Выбор головы/руки/уже выбранного
корпуса не меняется. Неподходящие значения или существующие запасные
варианты оставляют исходный выбор без изменений.

Сохраняется весь исходный пакет точки, а не только её координаты.
В поддерживаемой ветке родной проверки хитшанса исходная точка в ноге
становится запасной. Если хитшанс корпуса не пройден, штатный код копирует
запасную точку и проверяет её обычным способом. Патч включается только для
ветки, где такой повтор уже предусмотрен ядром (флаг 0x400).

Патч не добавляет точку корпуса, если ядро её не рассчитало/не допустило,
не включает отключённые хитбоксы, не повышает урон, не отменяет проверку
хитшанса и не расширяет временное окно предикта. Он не гарантирует убийство
и не исключает промахи или ответный выстрел. Изменена проверенная ветка
выбора точки этого рабочего процесса; все альтернативные пути ядра не переписаны.

## Сохранённые изменения

- Исправления resize/DPI с разделением базовых и пиксельных размеров.
- Полные таблицы Child из 13 методов с пересылкой родных resize/DPI.
- Восстановление раскладки Visuals и Skinchanger после загрузки/выгрузки Lua.
- Skinchanger из трёх панелей и цвета редкости из каталога настоящих предметов.
- Ранее установленные модули проверки истории, интерполяции и прогноза позы.
  Прогноз ограничен двумя тиками, требует трёх согласованных записей и
  проверки объёма игрока на препятствия.
- 128 образцов рассеивания в ранее изменённой проверке 0x4332fd2b.
  Это число образцов, а не пространственных точек хитскана. Применение
  именно этой проверки ко всем режимам Rage не подтверждено.

Дополнительный BT, desync 60°, локальный инвентарь и общий обмен скинами
в эту версию не добавлены. Исходные игровые DLL не включены.

## Проверки

- 1264 случая выбора корпуса: здоровье, урон, хитгруппа, маски,
  доступность штатного повтора, повреждённые границы/координаты.
- 30 исполнений собранного x86-переходника и родного копирования точки;
  сохранение целочисленных регистров, SSE и MXCSR.
- 12 исполнений настоящей ветки перехода на запасную точку после отказа
  хитшанса (сама проверка хитшанса заменена контролируемым ответом).
- Предпросмотр через настоящий дочерний обработчик категорий при нулевых
  HWND/MenuAlpha; четыре объекта, разные размеры/DPI, восстановление clipping.
- Геометрия панели, процедурная модель, переключатели ESP и оконный ввод.
- Прежние проверки контролов, resize/DPI, Skinchanger и Lua lifecycle.
- Совместная установка четырёх модулей: 88 занятых байтов инструкций;
  остальные байты исходного образа сохранены.
- PE32 DLL/EXE, ресурсы, SHA256, ZIP CRC и манифест файлов.

Проверки используют закрытые x86 fixtures с заменёнными игровыми API,
выделением памяти и рендерером. Полный запуск защищённого ядра и игра
не выполнялись. Отчёты находятся в reports/. Исходный бинарный ресурс
ядра сохранён побайтно; полный высокоуровневый исходник ядра не восстановлен.

```sh
python -m pip install -r requirements-build.txt
python build_windows.py
python tests/validate_visuals.py
python tests/validate_body_preference.py
python tests/validate_release.py
python package_release.py
```
